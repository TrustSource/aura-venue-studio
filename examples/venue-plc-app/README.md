# Sample control application "Hotel Lobby"

A control application as an integrator writes it with Venue Studio for one installation. It belongs
to the integrator, not to Aurelia Audio.

`hotel-lobby.venueproj.json` refers to function libraries by name, version and vendor. The libraries
are fictional. There is no package registry and no established identifier (package URL or CPE) for
them, which is the situation this example is meant to show.
