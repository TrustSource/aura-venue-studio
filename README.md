# Aura Venue Studio

Engineering software for the Aura Venue Controller.

## Documentation

The Aura Venue example is documented in one place, in English and German:
**<https://aura-venue.trustsource.io>**

There you find what the products do, how the components fit together and why they are designed the
way they are. Architecture details of this repository are in [ARCHITECTURE.md](ARCHITECTURE.md),
changes in [CHANGELOG.md](CHANGELOG.md).

## Demo status

This is a demonstration, not a product. Aurelia Audio and Aura Venue are fictional; TrustSource
builds them as a worked example for product security documentation. The files in this repository do
not have to build or run, and some components are deliberately outdated or vulnerable. Do not use
any of it in a real device. Third-party products and parts named here are real and serve as examples
only; no affiliation or endorsement is implied.
